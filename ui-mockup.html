配置持久化为 JSON；支持导入导出。可将「表关系配置目录」扫描结果合并进同一份 JSON，供搜索与插入 SQL 使用。

设置

1. DDS / Copybook 路径组（有序）

每一组包含 DDS 目录 与 Copybook 目录。同组内按文件名自动配对： 表名.dds 与 表名.cbl（basename 一致即视为同一表）。 多组之间为有序列表：若不同组出现相同表名，以排序靠前的组为准。

  2. 排序 #2
2. 表关系

维护一对多 / 多对多 / 多对一等关系及 ON 条件；保存进配置 JSON 的 relations 数组。

ORDHDR one-to-many ORDDTL
ON ORDHDR.ORDNUM = ORDDTL.ORDNUM
CUSTMAS many-to-one ORDHDR
ON CUSTMAS.CUSTID = ORDHDR.CUSTID

需求：把表关系配置路径转为统一配置 JSON；后续搜索、插表、插字段只读该 JSON（及内存索引），避免直连多路径。

3. SQL 行长与压缩（Mocha / 5250）

与 Monaco 中「格式化」或「复制到剪贴板」动作联动：先按行长折行，再按需压缩。

4. 配置 JSON（导入 / 导出）

字段建议：version、ddsCopybookPathGroups[]、relations[]、sqlFormatting、tableRelationSourcePath、relationIndex（由路径扫描生成的查找用索引）。
